<h1 align="center">ZiZai 字在輸入法</h1>

<p align="center">免費的 macOS 中文字根輸入法</p>

字在是 macOS 的中文字根（形碼）輸入法，內建字根表，裝好就能打字；也可以匯入自己的 `.cin` 字根表、補字、改輸入碼。

## 下載

第一版準備中，尚未提供下載。

系統需求：macOS 13 以上。

## 特色

- **內建字根表**：「字在自建字根表（依規則自建，非官方）」，收錄 7 萬多字，包含 Unicode 擴充區。
- **三碼與四碼並存**：三碼（推導，非官方）和四碼不用切換。
- **擴充與自訂**：支援 `.cin` 格式（OpenVanilla、PIME、hime 等輸入法使用的碼表格式），可以補字、自訂輸入碼、停用不要的字。請使用你自己取得的 `.cin` 檔，字在不提供、也不散布第三方的字根表。
- **標點與符號**：按 `=` 再按一顆鍵，見 [符號字根表](docs/符號字根表.md)。
- **不連網**：輸入法本體不含任何連網程式，不記錄打字內容；不放廣告、沒有追蹤。見 [隱私權政策](PRIVACY.md)。
